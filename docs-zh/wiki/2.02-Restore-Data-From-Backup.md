# 从备份恢复数据

要了解备份包含什么以及导入如何替换你的数据，请参见 [[4.23-Managing-Your-Data|管理你的数据]] 和 [[3.06-User-Data|用户数据]]。

## 标准方法：通过导入/导出恢复

1. 打开**设置**（侧边栏或顶部栏中的齿轮图标）。
2. 打开**同步与备份**选项卡。
3. 在**自动备份**部分，**桌面版**（Electron）会显示备份位置：一行文字显示"备份保存到："，后跟路径。记下或复制此路径，以便需要时找到备份文件。
4. 在同一选项卡中，使用**导入/导出**部分。点击**从文件导入**，选择你的备份文件（例如来自自动备份文件夹的文件）。在警告时确认——导入**会替换所有当前数据**且无法撤销。

如果应用未找到数据但检测到有备份（例如启动时），它可能会提示你恢复最新的备份；你可以接受该提示，而无需使用"从文件导入"。

## 替代方法：先清除应用数据，然后导入

如果应用无法正常启动（例如[任务状态不一致](https://github.com/super-productivity/super-productivity/issues/3052)），请清除本地数据然后导入备份：

1. 找到你的备份文件（并可选择制作一个副本）。
2. 启动应用。
3. 打开开发者工具：**Ctrl+Shift+I**（Windows/Linux）或 **Cmd+Option+I**（macOS）。
4. 打开**应用程序**（Application）选项卡，然后在左侧边栏中点击**存储**（Storage）。
5. 点击**清除站点数据**。
6. 重新加载应用：**Ctrl+R**（Windows/Linux）或 **Cmd+R**（macOS）。
7. 在 Super Productivity 中，进入**设置 → 同步与备份 → 导入/导出**，使用**从文件导入**选择你的备份。
