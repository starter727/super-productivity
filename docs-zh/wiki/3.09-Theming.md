# 主题

自定义主题仅在**桌面版（Electron）**上受支持。你可以加载一个单一的自定义 CSS 文件，覆盖或扩展应用的样式。

## 内置主题

应用自带多个内置主题，你可以在设置中选择：

- Arc
- Catppuccin Mocha
- Cyberpunk
- Dark Base
- Dracula
- Everforest
- Glass
- Nord Polar Night
- Nord Snow Storm
- Rainbow

你还可以为单个项目和标签使用自定义主色、强调色和警告色进行颜色编码。

项目、标签、Today 和收件箱的主题设置还可以为浅色和深色模式分别使用背景图片。
当至少设置了一张背景图片时，会显示**变暗/变亮背景图片以增强对比度**滑块和**模糊背景图片**滑块。模糊滑块默认为 `0px`。当至少一种模式没有背景图片且仍使用应用的着色背景时，会显示**禁用彩色背景色调**设置。

## 自定义 CSS 主题

- 在用户数据文件夹中放置一个名为 **`styles.css`** 的文件（不要放在子文件夹中）。应用在启动时加载它并注入到渲染进程中。
- 该文件夹的位置以及如何找到它：[[3.06-User-Data|用户数据]]。无效的 CSS 可能加载失败并记录日志。
