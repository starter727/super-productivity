# 快速历史记录（Quick History）

快速历史记录（Quick History）是一个**以周为中心**的视图，显示你已在任务上记录的时间，限于**当年**。它使用与 [[4.21-Worklog]] 相同的基础数据——你任务的"每日花费时间"，来自活动任务和已归档任务——但将其呈现为紧凑的**周**列表，每个周有总时间和可展开的**日**，显示每个任务的条目。与工作日志屏幕不同，快速历史记录让你可以直接在视图中**编辑**任务在某天的花费时间。它的作用域与工作日志相同的**工作上下文**（项目或标签），用于快速回顾和纠正近期时间，而无需打开完整的多年工作日志。

关于时间如何记录以及"每日花费时间"来自何处，参见 [[4.14-How-Time-Is-Logged]]。关于完整的工作日志（所有年份，只读，可导出），参见 [[4.21-Worklog]]。

## 快速历史记录 vs 工作日志

| 方面         | 快速历史记录                                           | 工作日志                                                   |
| ------------ | ------------------------------------------------------- | --------------------------------------------------------- |
| **时间范围** | 仅当年                                                 | 所有年份（完整归档）                                      |
| **结构**     | 周 → 日 → 任务条目                                     | 年 → 月 → 日（或年 → 周 → 日）→ 条目                     |
| **目的**     | 紧凑的近期摘要，带有内联时间编辑                        | 详细的逐日日志，用于回顾和导出                            |
| **编辑**     | 是 —— 你可以更改每个任务每天的花费时间（内联）         | 否 —— 只读视图和导出                                      |
| **作用域**   | 与工作日志相同：活动工作上下文（项目或标签）            | 相同：活动工作上下文                                       |
| **访问**     | 工作上下文菜单（例如项目或标签）→ 快速历史记录          | 工作上下文菜单 → 工作日志                                 |

两个视图都是从同一来源**生成**的：当前上下文中活动和已归档任务，及其"每日花费时间"数据。导航到任一屏幕都会触发该数据的刷新。因此快速历史记录是工作日志使用的相同信息的**聚焦切片**——当年，按周——外加内联纠正时间的能力。

## 快速历史记录显示什么

- **周** —— 当年每周一行，带有**周号**和该周**总花费时间**。周通常按**最近优先**排序。
- **日** —— 每周可以展开以显示记录了时间的**日**。对于每一天，你会看到：
  - 该天**总花费时间**
  - **日志条目数**（该天有时间���任务）
  - 该天的**工作开始/结束**时间（如果配置了）
  - 该天的**简单计数器**（例如秒表或点击计数器），如果你使用它们
- **每天的���务列表** —— 展开一天会显示一个**按任务表格**：任务标题，以及每个任务在该天花费的时间。只有**已完成**或**超过一秒**的任务才会显示，使列表保持相关性。对于**叶子任务**（无子任务），时间可以**内联编辑**——你可以更改该任务在该天的时长。对于父任务，表格显示子任务时间的**总和**（此视图中只读）。

因此你可以快速回答"这周我做了什么？"和"这天我记录了什么？"，并可以选择在不打开任务或完整工作日志的情况下修正时间。

## 它回看多远

快速历史记录只包含**当年**。如果选定工作上下文中当年没有记录的时间，视图会显示消息，例如"当年无数据"。对于更旧的数据（前几年），使用**工作日志**视图，它包含所有年份。

## 数据源和刷新

- **来源** —— 与工作日志相同：当前项目或标签的**活动任务**和**已归档任务**，及其"每日花费时间"以及可选的工作开始/结束和简单计数器数据。应用从该数据构建**基于周的结构**（年 → 周 → 日）。
- **刷新** —— 与工作日志类似，快速历史记录在你**导航**到快速历史记录屏幕时刷新（或当共享的工作日志刷新运行时）。它不会在追踪时实时更新；打开视图或刷新以查看最新数据。
- **作用域** —— 你从**项目**或**标签**（工作上下文菜单）打开快速历史记录。你看到的数据仅用于该项目或标签。

## 内联编辑和持久化

当你在快速历史记录中**编辑**任务在某天的时间时，应用更新该任务在该日期的"每日花费时间"。更改以与其他时间更改相同的方式持久化（例如追踪后或空闲重新分配后），因此更新后的值出现在工作日志、报告和指标中。内联编辑仅适用于**叶子任务**；父任务显示子任务时间的总和，不在此处编辑。

## 在哪里找到它

快速历史记录可从**工作上下文菜单**（当前项目或标签的菜单）访问，与**工作日志**和**指标**并列。你可以为项目或标签打开它；路由反映上下文（例如 project/:id/quick-history 或 tag/:id/quick-history）。

## 总结

- **快速历史记录** = 当年**每日花费时间**的以周为中心的视图，作用于活动项目或标签。
- **与工作日志相同的数据** —— 从活动 + 已归档任务构建；不同的布局（周优先，仅当年）和**每个任务每天时间的内联编辑**。
- **工作日志** = 所有年份，只读，详细逐日，可导出；**快速历史记录** = 当年，逐周，带有内联时间编辑。
- **导航时刷新**；**作用域** = 当前工作上下文（项目或标签）。
