# 添加任务

本操作指南介绍如何向列表中添加新任务。关于子任务、计划、重复任务和问题关联任务，请参见 [[2.04-Manage-Subtasks|管理子任务]]、[[2.05-Manage-Scheduled-Tasks|管理计划任务]]、[[2.06-Manage-Repeating-Tasks|管理重复任务]] 和 [[2.07-Manage-Task-Integrations|管理任务集成]]。

## 打开添加任务栏

**从顶部栏：** 点击顶部栏中的**添加新任务**按钮（加号图标）。添加任务栏打开，光标聚焦在输入框中。

**使用键盘：** 按 **Shift+A**（"添加新任务"的默认快捷键）。你可以在 [[3.02-Settings-and-Preferences|设置与偏好]] → 键盘中更改或确认按键；参见 [[3.03-Keyboard-Shortcuts|键盘快捷键]]。

## 创建任务

1. 打开添加任务栏后，在输入框中输入任务标题。占位符显示一个示例：**A task title #tag @16:00 t25m**（你可以在标题中使用 **#tag**、**@time**、**@date** 和 **[t]time**；见下文）。
2. 按 **Enter** 或点击**添加任务**按钮（输入框旁边的加号图标）。任务被添加到当前项目或上下文（Today / 标签）中。

新任务出现在列表的**顶部**或**底部**，取决于添加栏设置（见下方的"添加到顶部或底部"）。

## 标题中的快捷语法

输入标题时，你可以使用：

- **#tagName** —— 将任务添加到一个标签（例如 `#work`）。如果该标签不存在，你可以在添加任务时创建它。
- **@16:00** 或 **@09:30** —— 设置任务的截止时间（仅提供时间时默认为今天）。
- **@tomorrow**、**@next week** 或一个日期 —— 设置截止日期。你可以与时间结合使用（例如 **@tomorrow @14:00**）。
- **[t]25m** —— 设置任务的估算时间。你也可以通过在末尾添加 `/` 来添加先前在任务上花费的时间（例如 `t30m/`）。`t` 标签是可选的，即使省略，快捷语法也能正常工作。

更多可用快捷语法标签信息，请参见 [[3.04-Short-Syntax|快捷语法]]。

添加任务栏还有**标签**、**计划**和**估算**按钮，无需输入即可设置这些内容。在计划/日程视图中，添加栏可能显示不同的选项（例如"计划到今天"）。

## 添加到顶部或底部

输入框旁边有一个按钮，用于切换新任务是添加到列表的**顶部**还是**底部**。工具提示显示"添加到顶部（Ctrl+1）"或"添加到底部（Ctrl+1）"。你也可以按 **Ctrl+1**（或你配置的按键）进行切换。这适用于你添加的下一个任务。

## 添加到待办清单或今天（如果项目有待办清单）

如果当前项目启用了**待办清单**（Backlog），会显示另一个按钮：**添加到待办清单** / **添加至今天**。它切换新任务是添加到项目的**待办清单**还是**今天的列表**中。图标和工具提示（"添加到待办清单"与"添加至今天"）显示当前模式。

## 添加现有任务或问题（搜索模式）

点击添加任务栏中的**搜索**图标（或按 **Ctrl+2**，如果已配置）切换到**问题搜索**模式。占位符变为"添加现有任务或问题……"。你可以搜索：

- **归档**或其他项目中的任务 —— 选择一个以将其添加到当前上下文。
- 来自已配置集成（Jira、GitHub 等）的**问题** —— 选择一个以将其添加为关联任务。

输入进行搜索，然后从列表中选择一个项目进行添加。再次点击搜索按钮或按 **Ctrl+2** 可禁用搜索模式，返回正常的"创建新任务"模式。

## 新任务去向

- **项目视图：** 任务被添加到**当前项目**。如果开启了"添加到待办清单"，则进入项目待办清单；否则进入主列表（或今天的列表，取决于上下文）。
- **Today / 标签视图：** 任务被添加到**当前标签**（例如 Today）。它们也属于某个项目；如果你在某个项目的 Today 视图中，则该任务属于该项目。
- **日程/计划视图：** 当你在此处使用添加栏时，你可以为特定日期（例如今天）计划任务；该任务将被安排到那一天。

## 从日程/计划视图添加任务

在日程或每日计划视图中，你可能会看到某一天的**添加**按钮（加号图标和"添加"标签）。点击它将在原地打开相同的添加任务栏；可以创建任务并计划到那一天。创建任务后内联添加栏会关闭。
