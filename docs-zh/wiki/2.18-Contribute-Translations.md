# 贡献翻译

如何为 Super Productivity 添加或更新翻译。

翻译文件是 `src/assets/i18n/` 中的 JSON 文件（例如 `de.json`、`fr.json`）。英语 (`en.json`) 是回退语言：缺失或空值会显示英语文本。

## 步骤

1. 打开 `src/assets/i18n/` 中对应你的语言的翻译文件。
2. 仅编辑字符串值。保持相同的嵌套结构和 SCREAMING_SNAKE_CASE 键名。
3. 如果你希望使用英语回退，将键保留为 `""`；除非你提供真正的翻译，否则不要将英语文本复制到空字符串中。
4. 本地运行应用（[[2.11-Run-the-Development-Server|运行开发服务器]]）并检查 UI。
5. 提交包含已更改的 JSON 文件的拉取请求。

## 格式和约定

- 嵌套 JSON；仅更改字符串值，不更改键或结构。
- 优先使用简短清晰的文本（UI 空间有限）。
- 使用 `en.json` 作为上下文和键名的参考。

## 翻译工具

要查找缺失的键并保持文件同步，请使用仓库中描述的脚本：

**[docs/i18n-script-usage.md](https://github.com/super-productivity/super-productivity/blob/master/docs/i18n-script-usage.md)**（以及 `tools/add-missing-i18n-variables.js`）。

完整的贡献者说明：[docs/TRANSLATING.md](https://github.com/super-productivity/super-productivity/blob/master/docs/TRANSLATING.md)。
