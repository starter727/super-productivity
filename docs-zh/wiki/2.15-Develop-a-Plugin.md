# 开发插件

如何为 Super Productivity 创建和测试自定义插件。

插件通过自定义 UI、钩子（例如任务完成时）以及对任务、项目和计数器的 API 访问来扩展应用。它们在沙箱中运行；iframe 插件必须内联 CSS 和 JavaScript。

## 快速步骤

1. 创建一个文件夹，至少包含：
   - `manifest.json`（id、名称、版本、描述、manifestVersion、minSupVersion）
   - `plugin.js`（加载时运行；可以注册头部按钮、快捷键、钩子），或
     `index.html` 用于仅 iframe 的插件
2. 添加 `index.html` 并在清单中设置 `iFrame: true` 以使用自定义 iframe UI。如果所有行为都在 `index.html` 中，则可以省略 `plugin.js`。
3. 在应用中：**设置** → **插件** → **从文件夹加载插件**，然后选择你的插件目录。
4. 使用 DevTools（F12 或 Ctrl+Shift+I）进行调试。

## 完整文档和示例

完整的插件指南和 API 位于仓库中：

**[docs/plugin-development.md](https://github.com/super-productivity/super-productivity/blob/master/docs/plugin-development.md)**

它涵盖：

- 清单字段、插件类型（JavaScript vs iframe）和安全性
- 可用的 API 方法（任务、项目、标签、计数器、通知、对话框）
- iframe 插件的主题变量和 UI Kit
- 最佳实践和测试

仓库中的示例插件：`packages/plugin-dev/yesterday-tasks-plugin`、`procrastination-buster`、`api-test-plugin`。对于 UI 密集型插件：`packages/plugin-dev/boilerplate-solid-js`。TypeScript API 类型：`packages/plugin-api/src/types.ts`。
