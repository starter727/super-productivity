# 搭建开发环境

如何配置环境变量和生成配置以进行开发和构建。

应用使用静态环境文件来设置标志（dev/prod/stage）以及 `.env` 文件来保存密钥和动态值。来自 `.env` 的值被转换为 TypeScript 常量，因此你可以使用类型安全的导入，而不是 `process.env`。

## 一次性设置

```bash
cp .env.example .env
```

编辑 `.env` 并添加你需要的任何密钥（例如可选集成的 API 密钥）。不要提交 `.env`；生成的文件 `src/app/config/env.generated.ts` 已被 gitignore。

## 在代码中使用变量

```typescript
import { ENV } from './app/config/env.generated';

const value = ENV.SOME_KEY;
```

或者使用辅助函数：

```typescript
import { getEnv, getEnvOrDefault } from './app/util/env';

const value = getEnv('SOME_KEY');
const withDefault = getEnvOrDefault('SOME_KEY', 'default');
```

当你运行任何构建或服务命令时，类型和键会从 `.env` 派生。

## 添加新变量

1. 将键和值添加到 `.env`。
2. 运行 `ng serve` 或构建命令，以便重新生成 `env.generated.ts`。
3. 在代码中使用 `ENV.NEW_KEY` 或 `getEnv('NEW_KEY')`。

## 静态与动态配置

- **静态**：`src/environments/environment.ts`、`environment.prod.ts`、`environment.stage.ts`（生产/阶段标志、版本）。
- **动态**：`.env` → `src/app/config/env.generated.ts`（密钥和每个开发者的值）。
