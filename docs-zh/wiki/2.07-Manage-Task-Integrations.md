# 管理任务集成

本操作指南介绍如何设置和使用问题集成（Jira、GitHub、GitLab 等）以及日历，以从外部系统导入和关联任务。关于集成如何工作的概述，请参见 [[4.24-Integrations|集成]]。关于各提供商支持工作日志、状态转换、子任务和其他功能的对比，请参见 [[3.07-Issue-Integration-Comparison|问题集成对比]]。

## 打开问题和日历面板

**问题提供商面板**（集成与日历）是一个侧面板，列出你已配置的提供商，并允许你搜索和添加问题或日历事件作为任务。

**从顶部栏：** 点击显示或隐藏问题提供商面板的面板按钮。其工具提示为**显示/隐藏问题提供商面板**。在桌面版中，它出现在顶部栏中；在移动版中，它在侧边菜单中。

**使用键盘：** 如果已配置，使用"显示/隐藏问题提供商面板"的快捷键（参见 [[3.02-Settings-and-Preferences|设置与偏好]] → 键盘和 [[3.03-Keyboard-Shortcuts|键盘快捷键]]）。

## 添加新的集成（问题提供商或日历）

1. 打开问题提供商面板（见上方）。
2. 点击**最后一个选项卡**——带有**加号（添加）** 图标的那个。视图显示两个部分：**连接日历**和**设置问题提供商**。
3. **对于日历：** 在**连接日历**下，点击**Google 日历**、**Outlook 365** 或 **iCal 其他**。会打开一个配置对话框（例如 iCal 的 URL，或 Google/Outlook 的 OAuth）。填写详细信息并保存。
4. **对于问题提供商：** 在**设置问题提供商**下，点击你想要的提供商：**Jira**、**Trello**、**GitHub**、**Redmine**、**GitLab**、**CalDAV**、**Open Project**、**Gitea**、**Linear** 或 **ClickUp**。会打开一个配置对话框。输入所需字段（主机 URL、令牌或密码、项目/仓库 ID 等——具体字段取决于提供商）。保存以创建集成。

### 日历集成：iCal 与 CalDAV（例如 Nextcloud）

**iCal** 和 **CalDAV** 是两种不同的集成，需要**不同的链接类型**：

- **iCal（日历）：** 使用**订阅**或**导出** URL。无需登录。应用在日程/计划中显示**事件**（VEVENT）。在 **Nextcloud** 中，使用"复制订阅链接"并将其粘贴到应用中的"iCal 源 URL"中。**不要**使用"复制私人链接"用于 iCal——那是给 CalDAV 用的。
- **CalDAV：** 使用你的用户和日历的 **CalDAV URL**，并输入**用户名和密码**。应用显示**任务/待办事项**（VTODO）并可以同步完成状态回来。在 **Nextcloud** 中，使用"复制私人链接"（或 CalDAV 日历 URL，例如 `…/remote.php/dav/calendars/<USER>/<CALENDAR>/`）。**不要**使用订阅链接用于 CalDAV。

如果集成"不工作"，请检查你是否使用了正确的链接和正确的提供商（iCal vs CalDAV）。更多详情请参见 [[4.24-Integrations|集成]] 和 [[3.07-Issue-Integration-Comparison|问题集成对比]]。

保存后，面板中会出现该提供商的一个新**选项卡**。你可以有多个同类型的实例（例如两个 Jira 配置），并通过拖拽重新排列选项卡。

## 添加问题或日历项作为任务

1. 打开问题提供商面板并选择提供商的**选项卡**（例如 Jira 或 GitHub）。
2. **对于问题提供商：** 在**搜索**字段中，输入查询（语法取决于提供商；可能会显示提示或搜索语法链接）。匹配的问题会列出。点击问题旁边的**添加（加号）** 按钮以将其添加为当前项目中的任务。该任务与该问题关联。
3. **对于日历（例如 iCal）：** 选项卡可能显示议程或事件列表。使用该选项卡中的控件来添加事件作为任务或打开它，具体取决于日历集成。

从面板添加的任务创建在**当前项目**中（或为该提供商设置的默认项目中；见下文）。

## 编辑或重新配置集成

**从提供商选项卡：** 在提供商选项卡的**标题栏**中有一个**设置（齿轮）** 图标。点击它以打开相同的配置对话框，更改主机、令牌、项目或其他选项。保存以应用。

**从选项卡标签：** **长按**（或长点击）提供商的**选项卡**（带有提供商图标和缩写的选项卡）。配置对话框打开。这在移动端或选项卡已选中时很有用。

## 为集成设置默认项目

当提供商设置了默认项目时，从该提供商选项卡添加的新问题将在该项目中创建。在提供商选项卡的**标题栏**中，你可能会看到一个箭头和项目名称；这就是当前的默认项目。要更改它，打开提供商的**设置**（齿轮图标或长按选项卡）并在对话框中设置默认项目（如果提供商支持）。

## 从添加任务栏添加现有问题（搜索模式）

你也可以在不打开问题面板的情况下添加问题（以及现有任务）：

1. 打开**添加任务栏**（例如 **Shift+A** 或"添加新任务"按钮）。
2. 点击**搜索**图标或按 **Ctrl+2**（如果已配置）切换到**问题搜索**模式。占位符变为"添加现有任务或问题……"。
3. 输入以在已配置的提供商和你的任务/归档中搜索。从列表中选择一个问题以将其添加为当前上下文中的关联任务。

关于添加任务栏和搜索模式的更多信息，请参见 [[2.03-Add-Tasks|添加任务]]。

## 项目级集成设置

某些集成可以**按项目**配置（例如使用哪个 Jira 项目）。打开项目的**项目设置**（通过项目菜单或侧边栏），查找**问题集成**或提供商特定部分。你可以在此处将项目关联到特定问题提供商，或覆盖该项目的集成设置。

## 故障排除

- **搜索中没有问题 / "检查你的配置！"** 打开提供商的**设置**（选项卡中的齿轮图标）并检查主机 URL、令牌和项目/仓库 ID。如果对话框提供测试连接，请尝试。对于 **Web 应用**中的 Jira，可能需要浏览器扩展；如果是这样，选项卡会显示提示。
- **提供商选项卡被禁用：** 当提供商被禁用时，选项卡显示为灰色。长按选项卡（或通过其他路径使用设置齿轮）以打开对话框并重新启用它。
- **问题不更新：** 某些提供商按间隔轮询更新。检查提供商的配置中是否有"每隔 X 检查更新"或轮询间隔选项。刷新选项卡中的列表也可能会触发更新。
