# 管理重复任务

关于重复配置如何工作以及何时创建实例，请参见 [[4.13-Repeating-Tasks|重复任务]]。

## 打开重复任务对话框（添加或编辑）

**从任务：** 打开任务（点击以在右侧打开任务详情面板）。在面板中找到**重复**行（重复图标和"重复"标签）。点击该行上的**添加**（加号）或**编辑**（铅笔）控件。对话框打开，标题为**添加重复任务配置**（新建）或**编辑重复任务配置**（已有）。只有主任务（不是子任务）和非问题关联任务才会显示"重复"行；从 Jira 或 Git 导入的任务不能重复。

**从计划列表：** 前往**计划任务**页面（例如通过 **Shift+S** 或"前往计划任务"快捷键）。在**重复任务**部分，每个重复任务显示为一个卡片。点击卡片（带有重复图标和重复文本的行）以打开该配置的**编辑重复任务配置**对话框。

你也可以从重复任务实例或日程/计划上的重复投影（例如通过点击重复图标或事件）打开该对话框。

## 创建新的重复任务

1. 打开一个**主任务**（不是子任务，不是来自问题）并在任务详情面板中打开**重复**行（见上方）。对话框标题为**添加重复任务配置**。
2. 输入**任务标题**（或保留任务当前的标题，通常已预填）。
3. 在**重复配置**中，选择一个快速设置：
   - 每天
   - 每个周一至周五
   - 每周的 &lt;星期几&gt;（例如每周三）
   - 每月的 &lt;日期&gt; 日
   - 每年的 &lt;月日&gt;
   - 自定义重复配置 —— 然后使用额外字段（见下文）。
4. 对于**自定义**，设置：
   - 每隔 —— 数字（1–1000）。
   - 重复周期 —— 天、周、月或年。
   - 计划类型（仅适用于间隔 > 1）：固定计划（每隔 X 从开始日期起）或完成后（完成后 X）。
   - 开始日期 —— 模式开始的时间（必填）。
   - 对于周周期：勾选任务应在一周中的哪些天（周一至周日）重复。
5. 可选设置**要添加的标签**（芯片列表）。
6. 可选设置**计划开始时间**（例如 15:00；留空表示全天）。如果你设置了时间，会显示**提醒时间**——选择何时被提醒（例如开始时、提前 5 分钟）。
7. 可选设置**默认估算**（时长）。**顺序**（数字）控制当多个重复任务同时创建时的创建顺序；请参见对话框中的字段描述。
8. 在高级部分：**默认笔记**、**继承子任务**（从最新实例复制子任务到下一个实例），以及如果启用继承，**禁用自动更新子任务**（当最新实例更改时不更新继承的子任务）。
9. 点击**保存**。当你打开项目或应用时，将根据模式创建新实例。

## 为重复任务添加时间和提醒

1. 打开重复任务配置（任务详情面板 → 重复，或计划列表 → 点击重复任务卡片）。
2. 设置**计划开始时间**（例如 15:00）。留空表示全天任务。
3. 设置时间后，会显示**提醒时间**。选择一个选项（例如开始时、开始前 5 分钟）。
4. 点击**保存**。

## 为实例设置默认时间估算

在重复任务对话框中，设置**默认估算**（时长）。新实例将使用此估算，除非你逐个任务更改。点击**保存**。

## 为重复任务配置添加标签

在对话框中，使用**要添加的标签**来添加一个或多个标签。新实例将带有这些标签。点击**保存**。

## 在新实例中继承子任务

1. 打开重复任务配置。
2. 启用**继承子任务**。说明文字会介绍最近任务实例中的子任务将与重复任务一起重新创建。
3. 可选启用**禁用自动更新子任务**，这样当你修改最新实例上的模板子任务时，现有实例不会自动更新。
4. 点击**保存**。

## 编辑重复任务配置

打开配置（从任务详情面板的**重复**行，或从计划列表上的**重复任务**部分点击卡片）。更改**任务标题**、**重复配置**、**开始日期**、星期几、**计划开始时间**、**提醒时间**、**默认估算**、**顺序**、**默认笔记**、标签或继承选项。点击**保存**。

## 删除单个实例（例如"仅今天"）

1. 打开该重复任务的**编辑重复任务配置**对话框（例如从任务实例或计划列表）。
2. 如果今天（或你打开时对应的日期）的实例可以被移除，会显示一个按钮：**移除今天**或**移除 &lt;日期&gt;**。点击它仅删除该实例。重复配置和其他实例不变。

## 删除整个重复任务（停止所有未来实例）

1. 打开**编辑重复任务配置**对话框。
2. 点击**移除**。这将移除重复配置。未来将不再创建实例；现有任务实例保留，直到你单独删除它们。
