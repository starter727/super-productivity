# Wiki 文档框架

本 Wiki 基于 [Diátaxis](https://diataxis.fr/) 文档框架构建。关于如何实现的更实用描述，请参见 [Openedx](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#open-edx-diataxis-guide)。

> [Diataxis 框架](https://diataxis.fr/) 是一种实现技术文档质量的方法，并创建了系统化的组织方式。Diataxis 确定了四种文档模式：
>
> - [快速入门（Quickstart）](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#quickstart)：教你如何做某事
> - [操作指南（How-To Guide）](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#id2)：告诉你该做什么来解决问题或完成任务
> - [参考（Reference）](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#reference)：事实性的静态信息
> - [概念（Concepts）](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#concept)：解释某个事物的理论、背景、目的和/或效用

请参见 [[0.00-Wiki-Structure-and-Organization|Wiki 结构与组织]] 了解该框架目前如何实施的更多详情。
