# 时间如何被记录（How Time Is Logged）

Super Productivity 中的时间追踪围绕一个单一的**活动任务（active task）**构建：当你在一个任务上启动计时器时，该任务成为应用当前正在追踪的任务。时间以小的增量记录，存储在任务上（以及在上下文和归档中用于同步和历史记录），并持续直到你暂停或切换到另一个任务。理解启动和切换如何工作、时间如何记录和存储、空闲和完成如何处理，以及估算与实际时间的对比如何使用，有助于你有效地使用时间追踪。

## 启动任务

**启动**一个任务意味着使其成为时间追踪的**全局活动任务**。应用一次追踪**一个活动任务**。当你启动一个任务的计时器时，该任务成为活动任务；任何之前正在被追踪的任务不再活动——时间停止在其上累积，并开始在新任务上累积。你无需先暂停旧任务；启动另一个任务会自动**切换**活动任务。因此"启动"既开始追踪新任务，又有效地暂停了前一个任务。

活动任务显示在 UI 中（例如标题栏或时间追踪面板）。你可以明确暂停活动任务（停止计时器，不选择任何任务）或启动不同的任务；在两种情况下，前一个任务停止累积时间。

## 时间如何记录

时间以**滴答（tick）**方式记录：应用发出定期的"滴答"（小的时间间隔）并将每个滴答归因于当前活动任务。当滴答被处理时：

- 任务的**总花费时间**被更新。
- 任务的**每日花费时间**被更新，以便你可以查看每个日历日记录了多少时间。

更新立即应用于本地状态，因此 UI（例如计时器和任务时间显示）立即反映新时间。对于同步（例如 WebDAV 或 Dropbox），应用**批量处理**时间追踪更新（例如每几分钟一次），以减少同步操作次数，同时保持数据一致性。

## 时间追踪数据存储在哪里

时间存储在多个级别，以便应用可以显示准确的汇总、支持同步和保留历史记录：

- **任务级** —— 每个任务有**总花费时间**（该任务上曾记录的所有时间）和**每日花费时间**（按日历日细分）。这就是你在任务上看到的（例如"3h"或"今天 10m"），以及驱动剩余时间（估算减去花费时间）的内容。父任务可以显示来自其子任务的聚合时间。
- **上下文级** —— 应用维护每个工作上下文（例如每个项目或标签）的时间追踪状态，以便在正确的位置显示总计和历史记录。
- **归档** —— 已完成任务（及其时间）随着时间的推移移至归档。归档分两级（近期和旧）构建，以便同步和历史记录保持高效，同时旧数据仍可用于报告和备份。参见 [[4.20-Task-Archiving]]。

所以"我的时间在哪里？"的答案是：在任务上（总计和每日），在当前上下文的状态中，以及任务归档后的归档中。

## 空闲和暂停时间

当应用检测到你一直**空闲**（一段时间没有输入）时，它可以：

- **暂停当前任务** —— 活动任务被清除，时间停止累积。
- **处理空闲段** —— 你空闲时经过的时间可能从任务中**移除**，或留给你**重新分配**。当你回来时，应用可以显示一个对话框，让你将该空闲时间分配给同一任务、另一个任务或丢弃它。这使你的记录保持准确且在你可以控制之下。

空闲检测和重新分配对话框可在 [[3.02-Settings-and-Preferences]] 中配置。要点是：应用不会将空闲时间静默地归属于活动任务；它会暂停并给你机会修正记录。关于空闲检测和重新分配对话框的完整概述，参见 [[4.17-Idle-Time]]。关于持续工作后的休息提醒，参见 [[4.16-Break-Reminders]]。

## 标记任务完成

当你**标记任务完成**时：

- 任务的**完成状态**设置为已完成。
- **完成时间戳**被记录（完成的时间）。
- 取决于设置，应用可能会**自动添加**任务到今天的列表（例如用于回顾或指标）。

**完成_不会_停止时间追踪。** 如果计时器在标记完成时正在该任务上运行，它会继续运行。应用不会假设"完成"意味着"停止计时器"。要停止追踪，你必须**暂停**计时器或**启动**另一个任务。这种分离让你可以在列表中完成任务，但继续记录少量额外时间（例如收尾工作），或如果你的工作流需要，有意在已完成任务上追踪时间。

已完成任务（及其时间）保留在应用中，并包含在**报告和历史记录**中。当它们足够旧时，会移至归档；时间数据保持与任务关联，以便你可以分析过去的工作。

## 估算时间与实际时间

应用持续比较**花费时间**与**时间估算**，以显示进度并支持规划。比率（花费时间 ÷ 估算）给出了一个**进度**值（例如 1.0 = 估算的 100%）。此比较是：

- **在 UI 中显示** —— 进度指示器和任务时间显示（例如"2h / 3h"）在你记录时间时更新。
- **在指标中使用** —— 生产力和估算准确性可以使用相同的比较。
- **在报告中使用** —— 历史绩效和"估算与实际"视图使用存储的时间和估算。

因为花费时间在计时器运行时实时更新，进度值和任何依赖它的 UI 或指标会**自动重新计算**；你无需刷新。关于估算如何工作以及它们如何与记录时间交互的更多信息，参见 [[4.08-Time-Estimates]]。
