# 运行开发服务器

如何在本地或 GitHub Codespaces 中运行 Super Productivity 进行开发。

## 选项 1：本地

### 前提条件

- Node.js 20 或更高版本 ([nodejs.org](https://nodejs.org))
- Git

### 本地：克隆并安装

```bash
git clone https://github.com/super-productivity/super-productivity.git
cd super-productivity
npm i -g @angular/cli
npm i
npm run env
```

`npm run env` 一次性创建或更新环境文件；如果你添加或更改变量，请重新运行。

### 本地：启动前端

```bash
ng serve
```

打开 [http://127.0.0.1:4200](http://127.0.0.1:4200)。对于大多数 UI 和前端工作来说，这就足够了。[Redux DevTools](https://chrome.google.com/webstore/detail/redux-devtools/lmhkpmbekcpmknklioeibfkpmmfibljd) 可在浏览器中使用。

### 本地：运行完整应用（Electron）

```bash
ng serve
```

在第二个终端中：

```bash
npm start
```

Electron 窗口将加载开发服务器。

## 选项 2：GitHub Codespaces

1. 在 GitHub 上打开仓库。
2. 点击 **Code** → **Codespaces** → **Create codespace on main**（或加号图标）。
3. 等待开发容器构建。开发服务器通常会自动启动。
4. 打开**端口**（Ports）选项卡，找到转发的端口（例如 4200），然后使用**在浏览器中打开**或 Ctrl+点击 URL 以打开应用。

VS Code 设置在 codespace 中同步。要更改开发环境，请根据 [Codespaces 文档](https://docs.github.com/en/codespaces/setting-up-your-project-for-codespaces/adding-a-dev-container-configuration/introduction-to-dev-containers) 编辑 `.devcontainers/devcontainers.json`。
