# 使用 Docker 运行

如何运行 Super Productivity Web 应用的 Docker 容器，以及如何使用 WebDAV 集成。

## 仅运行 Web 应用

```bash
docker run -d -p 80:80 super-productivity/super-productivity:latest
```

打开 [http://127.0.0.1](http://127.0.0.1)。镜像默认匹配主机平台。使用 `--platform` 指定其他架构（例如 `linux/amd64`、`linux/arm64`、`linux/arm/v7`）。

数据存储在浏览器中；容器不提供持久化存储。

## 与 WebDAV 一起运行

从同一主机提供应用和 WebDAV 后端：

1. 将仓库文件复制到一个文件夹（例如 `sp/`）：

   ```bash
   git clone https://github.com/super-productivity/super-productivity.git
   mkdir -p sp
   cp super-productivity/docker-compose.yaml sp/
   cp super-productivity/webdav.yaml sp/
   cd sp
   ```

2. 编辑 `webdav.yaml`：设置用户名、密码和每个用户的目录（位于 `/data` 下），以便用户数据分开存放。

3. 启动堆栈：

   ```bash
   docker compose pull
   docker compose up -d
   ```

4. 打开 [http://127.0.0.1](http://127.0.0.1) 访问应用。在应用中，使用 WebDAV 基础 URL 设置同步：`http://127.0.0.1/webdav/`。

## 其他 Docker 选项

你可以向应用容器传递环境变量，以在设置页面上预填 WebDAV（或其他同步）设置。请参见仓库中的 `docker-compose.yaml` 获取变量列表。
