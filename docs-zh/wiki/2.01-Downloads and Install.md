## 已知问题和其他说明

### AppImages

如果在 Ubuntu 上遇到 AppImage 相关问题，请参见[此 issue 评论](https://github.com/super-productivity/super-productivity/issues/3193#issuecomment-2131315513)。

### Snap

要使用本地文件同步，你需要手动连接 `home` 接口：`snap connect superproductivity:home`

数据持久化警告

卸载 snap 包时，存储在 `~/snap/superproductivity/common/` 中的所有用户数据（任务、项目、设置）可能会被移除。卸载前请务必导出数据。如果你希望数据持久化在标准的 `~/.config/` 位置，请考虑使用 Flatpak、AppImage 或 .deb 包。

更多详情，请参见 [issue #6031](https://github.com/super-productivity/super-productivity/issues/6031)。

### Wayland

如果你使用 Wayland 并在"空闲状态"检测方面遇到问题，或看到渲染问题、VSync 错误、GLib-GObject 警告，请参考 [[3.99-Other|其他]] 中的一些解决方案。

### 通用 macOS DMG

同时包含 x86_64 和 arm64 文件的 DMG 也已[可用](https://github.com/super-productivity/super-productivity/releases/latest/download/superProductivity-universal.dmg)。

### Windows

由于认证问题，推荐使用 Microsoft Store。

在撰写本文时，"chocolatey"构建正在失败，需要强制使用"预发布"版本。
