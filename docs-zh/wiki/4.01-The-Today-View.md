# 今日视图（Today View）

今日视图是你每天工作的主要场所。它只显示今天到期的任务，让你专注于当前重要的事项。

## 显示内容

任务出现在今日视图中，前提是它们**安排在今天**——也就是说，它们的截止日期（due date）是当天。应用使用当前日期，并在日期发生变化时（例如午夜）自动更新列表。你安排在当天稍后的任务可能会在安排的时间之前不显示在列表中。

今日视图中任务的**顺序**是由你设定的。当你在此处重新排列任务时（例如通过拖放或键盘快捷键），该顺序将被保存，并在你下次打开今日视图时使用。

## 与项目和标签的区别

今日视图是一个**基于时间**的视图。其他工作视图是**基于类别**的：

| 方面                 | 今日视图                                                        | 项目和标签                                  |
| -------------------- | --------------------------------------------------------------- | ------------------------------------------- |
| **显示哪些任务**     | 今天到期的任务                                                  | 属于该项目或带有该标签的任务                |
| **顺序**             | 你在今日视图中设定的顺序                                        | 你在该项目或标签中设定的顺序                |
| **更新方式**         | 列表在日期变化或你更改截止日期时更新                            | 通过更改项目或标签来添加或移除任务          |

你不需要通过打标签来"添加"或"移除"今日视图中的任务。将任务安排到今天（或将其截止日期改为今天）就会将其放入今日视图；将截止日期改为其他日期则会将其移除。

## 规划器（Planner）与今日视图

当你将任务移到今天（例如通过"移至今天"或将其截止日期设为今天）时，它会被从所在的任何规划器日期中移除。今日视图和 [[4.03-Planner-View]] 都表示工作发生的时间——今天还是未来日期——因此一个任务要么在今天的列表中，要么在规划器的某一天中，不会同时存在。
