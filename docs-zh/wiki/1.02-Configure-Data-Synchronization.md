# 快速入门：设置和配置同步集成

本快速入门指南将引导你选择同步提供商并配置它，以便你的 Super Productivity 数据得到备份或在设备间同步。完成后你将启用同步，并知道如何确认它正常工作以及如何通过备份确保安全。

**学习目标：** 启用同步，选择提供商，完成其配置，并验证同步正常工作。

有关整体情况（你的数据包含什么、同步和备份如何配合），请参见 [[4.23-Managing-Your-Data|管理你的数据]]。有关提供商的详细对比，请参见 [[3.08-Sync-Integration-Comparison|同步集成对比]]。

---

## 开始之前

- **单台设备：** 同步是可选的。你可以用它来将数据备份到云端或本地文件夹。确保你知道如何 [[2.02-Restore-Data-From-Backup|从备份恢复数据]]，以备日后需要恢复。
- **多台设备：** 你需要**一个**同步提供商。每台设备可以使用不同的提供商，但通常你选择一个（例如 Dropbox 或 Nextcloud）并在所有设备上使用它，以使数据保持同步。

---

## 步骤 1：选择同步提供商

该应用支持五个选项。选择与你工作方式匹配的：

| 如果你想要……                                                    | 请选择              |
| ---------------------------------------------------------------- | ------------------- |
| 实时同步且可以接受 Beta 版软件                                   | **SuperSync (Beta)** |
| 无需运行自己的服务器的云同步                                      | **Dropbox**          |
| 使用你现有的 Nextcloud 服务器                                     | **Nextcloud**        |
| 使用其他 WebDAV 服务器                                           | **WebDAV**           |
| 备份或同步到此设备上的一个文件夹（仅限桌面版/Android）           | **Local file**       |

**不要**使用文件同步工具（例如 Syncthing、Resilio）在设备间同步 **Local file** 文件夹——这可能导致冲突。对于多设备同步，请使用 Nextcloud、WebDAV、Dropbox 或 SuperSync。

何时使用哪种的完整指导：[[2.08-Choose-Sync-Backend|选择同步后端]]。对比表和详情：[[3.08-Sync-Integration-Comparison|同步集成对比]]。

**结果：** 你知道将要设置哪个提供商。

---

## 步骤 2：打开同步设置

1. 打开**设置**（齿轮图标）。
2. 打开**同步与备份**选项卡。
3. 在**同步**部分，开启**启用同步**。
4. 从下拉菜单中选择你的**同步提供商**。

表单将显示所选提供商所需的字段。具体字段和选项见 [[2.09-Configure-Sync-Backend|配置同步后端]]。

**结果：** 同步已启用，正确的配置表单可见。

---

## 步骤 3：输入提供商的详细信息

填写你的提供商的表单。实际操作中需要的内容：

- **SuperSync：** 从服务器获取访问令牌（例如在应用中使用"打开服务器并获取令牌"），然后粘贴进去。可选择在**高级**下设置自定义服务器 URL 或启用加密。
- **Dropbox：** 通过应用的链接登录；应用中不存储密码。你可以设置**同步间隔**和**仅手动同步**，并可选择在**高级**下启用加密。
- **Nextcloud：** 输入**服务器 URL**、**用户名**和**应用密码**。如果你的登录名与用户名不同，请使用**登录名/邮箱（可选）**。如有需要，设置**同步文件夹路径**。同步间隔和仅手动设置适用；加密在**高级**下。
- **WebDAV：** 输入**基础 URL**、**用户名**和**密码**。如有需要，设置**同步文件夹路径**。同步间隔和仅手动设置适用；加密在**高级**下。
- **Local file（本地文件）：** 使用文件夹选择器（桌面版或 Android）选择**同步文件夹路径**。同步间隔和仅手动设置适用；加密在**高级**下。

如果你启用**加密**（SuperSync 或基于文件的），请在将同步此数据的每台设备上使用相同的密码或密钥。丢失密钥意味着数据无法解密。

**结果：** 配置已保存。应用将按设定的间隔自动同步（如果启用了"仅手动同步"，则仅在你触发同步时同步）。

---

## 步骤 4：确认同步正常工作

- **自动同步：** 等待下一次同步，或者从 UI 触发同步。检查同步状态或通知中的成功信息。
- **第二台设备：** 在另一台设备上，启用相同的提供商并登录或指向相同的账户/文件夹。首次同步后，数据应匹配（如果双方都有数据，可能会提示你选择"使用本地"或"使用远程"）。
- **仅备份（例如 Local file）：** 打开同步文件夹，确认同步文件存在并在同步后更新。

如果出现问题，请在 [[2.09-Configure-Sync-Backend|配置同步后端]] 和 [[3.08-Sync-Integration-Comparison|同步集成对比]] 中检查提供商的要求（例如 Nextcloud 用户名与登录名、WebDAV URL 格式、Web 应用的 CORS）。

**结果：** 你已验证同步运行，并且在适用的情况下，数据出现在远程端或另一台设备上。

---

## 步骤 5：记住备份和恢复

同步不能替代知道如何恢复。如果你的平台支持自动备份，请确保已启用，并且你知道如何从备份文件 [[2.02-Restore-Data-From-Backup|从备份恢复数据]]。备份和同步数据的存放位置：[[3.06-User-Data|用户数据]] 和 [[4.23-Managing-Your-Data|管理你的数据]]。

**结果：** 你已为同步和必要时恢复设置完毕。
