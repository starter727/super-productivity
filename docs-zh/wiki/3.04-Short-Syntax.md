# 快捷语法

Super Productivity 支持四种主要的快捷语法形式，用于快速向任务添加元数据：标签（`#`）、项目（`+`）、时间估算（`m`/`h`/`d`）和截止日期（`@`）。每种形式可以在 [[3.02-Settings-and-Preferences#global-settings.Short-Syntax|设置与偏好#全局设置-快捷语法]] 中单独启用或禁用。

## 支持的语法形式

### 标签语法（`#`）

- **符号：** `#`
- **用途：** 向任务添加标签。
- **语法：** `#<tag-name>`。`#` 前需要有一个空格。
- **参数：** 标签名（不区分大小写）。
- **有效：** `"Task #urgent"`、`"Meeting #work #important"`。允许多个标签。
- **无效：** `"Task#urgent"`（`#` 前无空格）——整个快捷语法运行返回无变化。如果其他令牌有效（例如 `"Task#urgent #other"`），则仅应用有效的标签，无效令牌保留在标题中。

### 项目语法（`+`）

- **符号：** `+`
- **用途：** 将任务分配给一个项目。
- **语法：** `+<project-name>`。`+` 前需要有一个空格。
- **参数：** 项目标题或部分标题；最少 3 个字符。匹配基于前缀、不区分大小写，比较时会移除空格。当多个项目匹配时，优先选择标题最短的匹配项目。
- **有效：** `"Task +Important Project"`、`"Task +Project"`（部分匹配）。包含 `+`、`#`、`@` 或类似字符的项目名称也受支持；解析器使用向前查找，因此名称内的这些字符不会终止令牌。
- **无效：** `"Task+Project"`（`+` 前无空格）——不会应用任何项目。

### 时间估算语法

- **符号：** `m`（分钟）、`h`（小时）、`d`（天）。可选前缀 `t`。可选 `/` 分隔已花费时间和时间估算。
- **用途：** 设置已花费时间和/或时间估算。
- **语法：** `[t]<number><unit>[ <number><unit>...][/ <number><unit>...]`。单位：`m`、`h`、`d`。支持小数（例如 `1.5h`）。`/` 前：当天已花费时间。`/` 后：时间估算。支持 `1h 30m` 这样的组合。
- **参数：** 已花费时间（`/` 前）：例如 `30m`、`1.5h`、`2d`。时间估算（`/` 后）：例如 `1h`、`90m`、`0.5d`。可以省略一侧：`30m/` 仅设置已花费时间；`1h` 仅设置估算。
- **有效：** `"Task 10m"`、`"Task 1h/2h"`、`"Task 30m/"`、`"Task t1.5h"`、`"1h 30m / 1d 12h"`。
- **默认值：** `h` = 60 分钟，`d` = 8 小时（工作日）。

### 截止日期语法（`@`）

- **符号：** `@`
- **用途：** 设置任务的截止日期/时间。
- **语法：** `@<date-time-expression>`。`@` 和表达式之间不能有空格。
- **参数：** 基于 Chrono 的解析器支持的日期/时间表达式（例如 `4pm`、`friday`、`tomorrow 19:00`、`2030-10-12T13:37`）。
- **有效：** `"Task @4pm"`、`"Task @friday"`、`"Task @tomorrow 19:00"`、`"Task @2030-10-12T13:37"`。
- **无效：** `"Task @ tomorrow"`（`@` 后有空格）——不应用截止日期，表达式从标题中移除。两位数的年份 50–99 会纠正为当前或下一个日历年份，以避免 Chrono 将其解释为年份（例如日期上下文中的 `90m`）。

## 正式语法和正则表达式模式

解析器为每种语法形式使用正则表达式。时间：可选 `t` 前缀、数字和小数点加 `m`/`h`/`d`、可选 `/` 用于已花费/估算。项目：`+` 加向前查找，使得项目名称内的分隔符（`#`、`@`、时间类令牌）不会终止匹配。标签：`#` 后跟字符，直到遇到特殊字符或空白。截止日期：`@` 后跟字符，直到遇到特殊字符。确切模式在 `short-syntax.ts` 中定义（例如 `SHORT_SYNTAX_TIME_REG_EX`、`SHORT_SYNTAX_PROJECT_REG_EX`、`SHORT_SYNTAX_TAGS_REG_EX`、`SHORT_SYNTAX_DUE_REG_EX`）。

## 默认值和行为

- **时间单位：** `m` = 分钟，`h` = 60 分钟，`d` = 8 小时（工作日）。
- **仅已花费时间：** 例如 `30m/` 设置当天的已花费时间，不设估算。
- **仅时间估算：** 例如 `1h` 设置估算，不设已花费时间。
- **日期解析：** 使用自定义的基于 Chrono 的解析器，对两位数的年份 50–99 进行年份纠正（当前/下一年）。
- **项目匹配：** 基于前缀、不区分大小写、移除空格；最短匹配项目标题优先。
- **标签模式：** `combine`（默认）或 `replace`；可在设置中配置。

## 快捷语法支持的位置

**支持：**

- 添加任务栏（使用快捷语法创建任务的主要位置）。
- 添加新任务时（例如通过共享的添加任务操作）。
- 当唯一更改是标题时的任务标题更新（重新解析语法）。

**不支持或禁用：**

- **问题关联任务：** 关联到外部问题的任务不能使用项目语法（参见 [[2.07-Manage-Task-Integrations|管理任务集成]]）。
- **禁用时：** 每种语法类型（标签、项目、时间、截止日期）可以在 [[3.02-Settings-and-Preferences#global-settings.Short-Syntax|设置与偏好#全局设置-快捷语法]] 中关闭；被禁用的形式会被忽略。
- **已归档或隐藏的项目：** 项目语法不匹配已归档或隐藏的项目。

## 解析和评估规则

1. **处理顺序：** 截止日期 → 项目 → 标签（时间与截止日期一起处理）。
2. **标题清理：** 处理后，解析出的语法会从任务标题中移除。
3. **标签创建：** 尚不存在的标签会被收集到 `newTagTitles` 数组中以便创建。
4. **返回值：** `shortSyntax()` 函数返回包含任务更改（以及 `newTagTitles`、`remindAt`、`projectId`）的对象，如果未解析到任何内容或语法被禁用，则返回 `undefined`。

## 错误处理

**格式错误的语法：**

- 无效语法被忽略；函数可能返回 `undefined` 或仅应用有效部分。
- 不会抛出异常；无效令牌会被跳过或适当地保留在标题中。
- 如果语法类型在设置中被禁用，则不处理该形式。

**边界情况：**

- 包含 `+`、`#`、`@` 或时间类模式的项目名称会被正确处理，以便项目令牌能被正确解析。
- 日期表达式中两位数的年份 50–99 会被纠正为当前或下一年。
- 与日期表达式在同一标题中的时间估算令牌（例如 `90m`）会分别解析，以免 Chrono 日期解析消耗掉时间估算。

## 添加任务栏行为

- **切换新任务位置：** 添加任务栏中的切换控件控制新任务是添加到列表顶部还是底部。
- **自动补全：** 添加任务栏可以在输入时建议标签、项目和日期表达式。

## 说明

- 快捷语法由 `shortSyntax()` 函数处理；它返回任务更改，或在不需要更改时返回 `undefined`。
- 所有四种语法形式都可以在 [[3.02-Settings-and-Preferences|设置与偏好]] 的全局快捷语法部分配置。
