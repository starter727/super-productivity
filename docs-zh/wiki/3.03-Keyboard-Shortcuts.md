# 键盘快捷键

Super Productivity 支持广泛的键盘快捷键系统。快捷键按功能分组，大部分可通过 [[3.02-Settings-and-Preferences|设置与偏好]] 由用户配置。

## 功能分组

可配置的快捷键分为以下类别：

- **全局（系统级）：** `globalShowHide`、`globalToggleTaskStart`、`globalAddNote`、`globalAddTask`。仅在 Electron/桌面版中可用。
- **导航：** `goToFocusMode`、`goToWorkView`、`goToScheduledView`、`goToTimeline`、`goToSettings`。
- **任务管理：** `taskToggleDone`、`taskAddSubTask`、`taskSchedule`、`taskDelete`、`taskEditTitle`、移动/选择任务操作等。
- **UI 面板：** `toggleIssuePanel`、`toggleBacklog`、`toggleTaskViewCustomizerPanel`、`addNewTask`、`addNewProject`、`addNewNote`、`focusSideNav`、`openProjectNotes`、`showSearchBar`、`triggerSync`、缩放。

项目 README（键盘快捷键部分）列出了最常用默认设置的子集。

## 全局快捷键

这些快捷键在应用中的任何地方都有效。

- `Shift`+`A`：打开添加任务栏
- `Shift`+`P`：打开创建项目对话框
- `Alt`+`N`：添加新笔记
- `Shift+D`：聚焦侧导航
- `Shift+N`：显示/隐藏笔记
- `C`：切换过滤/分组/排序面板
- `P`：显示/隐藏问题面板
- `Shift`+`F`：显示搜索栏
- `B`：显示/隐藏任务待办清单
- `W`：前往工作视图并聚焦第一个任务
- `F`：进入专注模式
- `Shift`+`T`：前往日程
- `Shift`+`S`：前往计划任务
- `<无默认绑定>`：前往设置
- `Ctrl`+`=`：放大（桌面版/Firefox/Chrome）
- `Ctrl`+`-`：缩小（桌面版/Firefox/Chrome）
- `Ctrl`+`0`（零）：默认缩放（桌面版/Firefox/Chrome）
- `Ctrl`+`S`：触发同步（如果已配置）

### 任务

以下快捷键适用于当前选中的任务（通过 Tab 键或鼠标选择）。

- `<无默认绑定>`：编辑标题
- `I`：显示/隐藏附加任务信息
- `N`：打开任务面板中的笔记/清单
- `T`：编辑估算/已花费时间
- `S`：打开当前聚焦任务的计划对话框
- `D`：将当前聚焦任务标记为完成
- `A`：为当前聚焦任务添加子任务
- `L`：附加文件或链接
- `Enter`：编辑当前聚焦任务的标题
- `Backspace`：删除当前聚焦任务
- `E`：打开将任务移动到项目的菜单
- `Q`：打开任务右键菜单
- `K`：选择上一个任务
- `J`：选择下一个任务
- `Ctrl`+`Shift`+`上箭头`：将当前聚焦任务在列表中上移
- `Ctrl`+`Shift`+`下箭头`：将当前聚焦任务在列表中下移
- `Ctrl`+`Alt`+`上箭头`：将当前聚焦任务移到顶部
- `Ctrl`+`Alt`+`下箭头`：将当前聚焦任务移到底部
- `Shift`+`B`：将任务移至任务待办清单
- `Shift`+`T`：将任务移至今天的任务列表
- `<无默认绑定>`：展开子任务
- `<无默认绑定>`：折叠子任务
- `Y`：切换对当前聚焦任务的时间追踪

#### 不可配置的快捷键

- `方向键`：在任务列表中导航
- `右箭头`：打开当前聚焦任务的附加信息面板
- `Ctrl`+`C` / `Cmd`+`C`：当焦点在任务上、没有选中文本且焦点不在输入框中时，复制当前聚焦任务的标题

## 可折叠分组

以下快捷键适用于焦点在可折叠分组标题上时（例如工作视图中的任务分组，如已逾期、今天、已完成、重复等）。

- `左箭头`：折叠聚焦的分组
- `右箭头`：展开聚焦的分组
- `Shift`+`左箭头`：折叠所有分组
- `Shift`+`右箭头`：展开所有分组
- `Enter` 或 `Space`：切换聚焦的分组

这些快捷键**不可配置**，且始终在分组标题上可用。

## 平台特定差异

**仅限 Electron/桌面版：**

- 全局快捷键（`globalShowHide`、`globalToggleTaskStart`、`globalAddNote`、`globalAddTask`）在应用运行时在整个系统中有效。
- 窗口缩放控制（`zoomIn`、`zoomOut`、`zoomDefault`）仅限桌面版。

**Android：**

- Android 上不显示键盘设置；键盘配置 UI 被隐藏。

## 可配置与保留快捷键

[[3.02-Settings-and-Preferences|设置与偏好]] 中列出的所有快捷键均可由用户配置。用户可以：

- 通过点击输入框并按所需的按键或组合键来更改任何快捷键；按 **Enter** 保存。
- 通过在输入框中按 **Escape** 来清除快捷键（设置为无绑定）。
- UI 会在两个操作使用相同快捷键时发出警告。

快捷键存储在全局配置（`GlobalConfigState.keyboard`）中，并持久化到 IndexedDB；如果启用了同步，它们会在设备间同步。没有快捷键被保留；每个快捷键都可以更改或禁用。

## 上下文相关行为

**任务级快捷键：** 需要任务焦点的操作（例如标记完成、添加子任务、计划、删除、移动）适用于当前选中的任务。选择方式为键盘（Tab/方向键）或鼠标。[[3.02-Settings-and-Preferences|设置与偏好]] 的键盘帮助文本描述这些操作适用于"当前选中的任务"。

**日程周视图：** `Ctrl`+鼠标滚轮更改周日程网格的垂直比例。该值本地存储，供未来访问日程时使用。

**专注模式覆盖层：** `Escape` 关闭覆盖层。如果专注会话或休息正在进行，它会在顶栏的专注按钮中继续。

**输入过滤：** 当焦点位于输入框、文本区域或可编辑内容元素中，或者有阻塞覆盖层（例如对话框）打开时，应用级和任务级快捷键不会被处理。这可以防止在输入时触发快捷键。

## 冲突与优先级

- **输入焦点：** 当焦点位于输入元素中或打开阻塞覆盖层时，跳过快捷键处理，以避免打断输入。
- **冲突：** 配置 UI 会在两个操作分配了相同的按键组合时发出警告。用户可以在快捷键字段中按 **Escape** 清除该绑定。

## 存储与定义

**快捷键定义位置：**

- 配置模型：`KeyboardConfig`（keyboard-config.model.ts）。
- 默认映射：`default-global-config.const.ts`（键盘部分）。
- 设置表单（显示哪些操作及其标签）：`keyboard-form.const.ts`。

**存储和使用位置：**

- 保存在 `GlobalConfigState.keyboard` 中；通过全局配置系统持久化到 IndexedDB；启用了同步时会同步。
- 运行时由 `ShortcutService` 处理；按键监听器在应用根组件（例如 `AppComponent`）中注册。

## 说明

快捷键系统在可用时使用 Keyboard API 布局映射，以使快捷键在不同键盘布局（例如 QWERTY、QWERTZ、AZERTY、Dvorak）下正确运行。用户的布局会被检测并用于将按键事件匹配到已配置的快捷键。
