# 标签：吃掉那只青蛙（Eat the Frog）

为了让自己更轻松地处理实际上最重要（有时也是最令人生畏）的任务，有一个被称为"吃掉那只青蛙"的概念。

其理念是为你的项目规划可操作的任务，并确保为每个任务分配一个标签（A、B、C 或 D）。每个字母代表不同的行动紧迫性类别：

A：未完成将对项目产生严重且相当直接的后果的任务。

B：重要的任务，但如果不立即完成，不会产生直接的严重后果。

C：完成了会很好，但可以等等的任务。

D：你在等待其他人提供信息的任务，或者应尽快委派出去的任务，因为所需的行动不取决于你。

最好每隔几天浏览一下计划，修订任务及其优先级。然后，每天早上或前一天晚上，只需查看'A'标签并确定当天的任务即可。
