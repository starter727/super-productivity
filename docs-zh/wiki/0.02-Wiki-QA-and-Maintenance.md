# Wiki 质量保证与维护

如 [[0.01-Style-Guide|样式指南]] 所述，CI 中使用 `pymarkdownlnt`。未来我希望在 PR 流程中集成链接检查（内部和外部）。此外，会定期运行仅外部链接的检查作业，以检查失效链接。

可以使用 [doc-link-checker-cli](https://github.com/djmattyg007/doc-link-checker-cli) 之类的程序以交互方式或在 PR 的 CI 中检查内部失效链接。它支持 GitHub Flavored Markdown：`doc-link-checker lint --md-type gfm`。

定期地，CI 作业可以使用以下工具之一检查 Wiki、主网站或"awesome 仓库"上的外部链接：

- [linkinator](https://jbeckwith.com/projects/linkinator)
- [broken-links (rust)](https://lib.rs/crates/broken-links)
- [broken-links (python)](https://pypi.org/project/broken-links)
- [linkchecker](https://linkchecker.github.io/linkchecker/index.html)
- [checklink](https://dev.w3.org/perl/modules/W3C/LinkChecker/docs/checklink)
