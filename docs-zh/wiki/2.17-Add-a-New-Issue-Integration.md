# 添加新的问题集成

如何向 Super Productivity 添加新的问题追踪器（例如 Jira、GitHub、GitLab 风格）。

新集成实现共享的 **IssueProvider** 模式：模型、API 服务和一个实现 `IssueServiceInterface` 的通用接口服务。然后该集成在核心问题模型和配置中注册。

## 高级步骤

1. 在 `src/app/features/issue/providers/` 下创建一个目录（例如 `my-provider/`）。
2. 添加模型文件（配置和问题类型）、API 服务以及实现 `IssueServiceInterface` 的通用接口服务。
3. 添加常量和配置表单部分；实现所需的接口方法（例如 `isEnabled`、`testConnection$`、`getById$`、`searchIssues$`、`getFreshDataForIssueTask`）。
4. 在 `issue.model.ts`（IssueProviderKey、IssueIntegrationCfg、IssueIntegrationCfgs、IssueProvider）、`issue.const.ts`（类型常量、ISSUE_PROVIDER_TYPES、DEFAULT_ISSUE_PROVIDER_CFGS、ISSUE_PROVIDER_FORM_CFGS_MAP）中注册提供商，并确保问题服务注入并使用它。
5. 可选择在提供商特定的子文件夹中添加 UI（问题内容、头部、配置）。
6. 运行应用，在设置中添加集成，测试连接和问题流程。
