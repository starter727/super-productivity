# 打包应用

如何为 Super Productivity 构建可分发的包（Electron）。

## 前提条件

- 开发环境已搭建（[[2.11-Run-the-Development-Server|运行开发服务器]]）
- Node.js 20+

## 构建包

```bash
npm run dist
```

这会使用 [electron-builder](https://github.com/electron-userland/electron-builder) 并为当前平台（如果配置了其他平台也会构建）生成安装程序。

## 自定义平台和选项

- **package.json**：编辑 `build` 属性以添加或删除平台和选项。
- **CLI**：使用 [electron-builder CLI](https://www.electron.build/cli) 进行一次性构建（例如不同的架构或格式）。
