# 选择同步后端

同步功能将你的完整 Super Productivity 数据（任务、项目、时间追踪、设置、归档等）在此应用与远程位置或其他设备之间进行备份和同步。你可以为每台设备配置**一个**同步提供商；每台设备可以使用不同的提供商（**同步提供商**设置不会在设备间同步）。关于提供商的详细对比，请参见 [[3.08-Sync-Integration-Comparison|同步集成对比]]。关于如何配置你选择的提供商，请参见 [[2.09-Configure-Sync-Backend|配置同步后端]]。

如果你仅在单台设备上使用 Super Productivity，则不需要使用任何同步后端。确保你已配置备份，并知道如何在因其他错误导致数据损坏时 [[2.02-Restore-Data-From-Backup|从备份恢复数据]]。

## 同步正在过渡中

应用正在转向新的**基于操作**的同步模型（变更以操作的形式发送，而不是完整的数据块）。**SuperSync** 是为该模型构建的后端，也是新开发的关注点。其他提供商（Dropbox、Nextcloud、WebDAV、本地文件）使用当前基于文件的同步，并**继续受支持**。代码中的"legacy"一词指的是较旧的技术实现，**并非**弃用或移除——开发者已声明 WebDAV 和本地文件在可预见的未来极有可能继续可用。选择适合你的设置和风险承受能力的选项。

## 标签含义

在**同步提供商**下拉菜单中，你会看到：

- **SuperSync (Beta)** —— 为基于操作的协议构建的新同步服务。正在积极开发中；实时同步和可选的服务器端端到端加密。**Beta** 表示它仍在稳定中；一些用户在 SuperSync 脱离 Beta 之前偏好基于文件的选项。
- **Dropbox** —— 通过你的 Dropbox 账户进行基于文件的同步。OAuth 登录；应用中不存储密码。广泛使用且稳定；未被弃用。
- **Nextcloud** —— 通过你的 Nextcloud Files WebDAV 端点进行基于文件的同步。对于 Nextcloud 使用此选项，因为应用会根据你的服务器 URL 和用户名构建 WebDAV 文件 URL。
- **WebDAV（实验性）** —— 通过任何其他兼容 WebDAV 的服务器（例如 ownCloud 或 NAS）进行同步。标记为**实验性**，因为不同提供商的 WebDAV 实现差异很大，可能无法在所有服务器上顺畅工作。该选项不会被移除。
- **本地文件（实验性）** —— 将同步文件保存到你机器上的一个文件夹（桌面版或 Android）。标记为**实验性**，因为行为可能取决于你如何使用该文件夹（例如同时运行多个应用实例）。对许多用户来说它工作良好。**不会被**移除。

## 何时使用哪种

- **你想要最新的同步栈并且可以接受 beta 版** → **SuperSync**（自托管或托管）。适合你想要实时同步和服务器上可选 E2E 加密的情况。
- **你想要云同步而不需要运行自己的服务器** → **Dropbox**。稳定且支持良好。
- **你已经在使用 Nextcloud** → **Nextcloud**。使用此选项而非通用 WebDAV，除非你特别需要自行输入完整的 WebDAV 基础 URL。
- **你已经在使用其他 WebDAV 服务器** → **WebDAV**。试试看；如果它能与你的服务器配合使用，那就没问题。如果不能，实验性标签反映了 WebDAV 兼容性各不相同。
- **你想要备份或同步到本地/网络文件夹（仅限桌面版或 Android）** → **本地文件**。无需账户，无需互联网。用于单台设备或备份到外部驱动器/NAS。**不要**使用 Syncthing 或 Resilio 等工具在设备间同步该文件夹——它们可能导致冲突。对于多设备同步，请改用 WebDAV、Dropbox 或 SuperSync。

## 重要提示：本地文件与 Syncthing/Resilio

本地文件同步将数据存储在你设备上的**一个文件夹**中。应用警告：**不要**使用文件同步工具（例如 Syncthing、Resilio）在设备间同步**该文件夹**——它们可能导致冲突。对于多设备之间的同步，请使用 Nextcloud、WebDAV、Dropbox 或 SuperSync。
