# 问题集成对比

本参考文档列出了每个**问题提供商**支持的功能：问题导入、状态转换、时间追踪/工作日志提交、评论、子任务、附件、过滤选项、自动导入到待办清单、故事点、截止日期以及其他提供商特定行为。使用它来比较提供商，或了解启用某个提供商后可以期待什么。

关于集成如何工作以及如何设置它们的概述，请参见 [[4.24-Integrations|集成]] 和 [[2.07-Manage-Task-Integrations|管理任务集成]]。关于**同步**提供商（WebDAV、Dropbox、SuperSync、本地文件）的对比，请参见 [[3.08-Sync-Integration-Comparison|同步集成对比]]。

## 核心功能（所有提供商）

每个问题提供商支持相同的基本操作：检查集成是否启用、测试连接、在外部系统中打开问题、通过 ID 获取问题、搜索问题以及将问题作为任务添加到应用中。所有提供商还支持刷新已导入的任务，以使外部系统中的更改（标题、状态等）在本地反映。每个提供商都有一个可配置的**轮询间隔**（或没有），用于控制应用检查更新的频率。除此之外，对状态转换、工作日志、评论、子任务、附件和过滤的支持取决于提供商和外部 API。

## 各提供商详情

### 1. Jira

- **问题导入：** 完整导入，支持 JQL 搜索。
- **状态转换：** 可配置的工作流（例如 打开 → 进行中 → 完成）。
- **工作日志：** 完整的工作日志提交和已花费时间追踪。
- **评论：** 评论追踪和显示。
- **子任务：** 子任务关系追踪和导入。
- **附件：** 附件映射和显示。
- **过滤：** 基于 JQL 的搜索；使用自定义 JQL 自动导入。
- **故事点：** 自定义字段支持。
- **分配：** 任务开始时重新分配；标记完成时更新分配人。

### 2. GitHub

- **问题导入：** 来自仓库的问题和拉取请求。
- **状态转换：** 不支持（问题在应用中是只读的）。
- **工作日志：** 不支持。
- **评论：** 评论追踪，可选的按用户名过滤。
- **过滤：** 在仓库内搜索；待办清单查询；基于用户名的评论过滤。
- **自动导入：** 可配置的待办清单查询。

### 3. GitLab

- **问题导入：** 从项目完整导入（云端或自托管）。
- **状态转换：** 在 GitLab 中关闭时自动标记为完成。
- **工作日志：** 之前支持；现已弃用。
- **评论：** 评论追踪，可选的按用户名过滤。
- **过滤：** 基于项目；范围（全部、已分配、已创建）；自定义问题过滤器（例如给定标签、史诗、里程碑）。
- **权重：** 支持。

### 4. Gitea

- **问题导入：** 支持。
- **状态转换 / 工作日志 / 评论 / 子任务 / 附件：** 不适用或不支持。
- **过滤：** 仓库、范围、标签。
- **自动导入：** 每个项目最近 100 个问题。

### 5. OpenProject

- **问题导入：** 支持。
- **状态转换：** 可配置的默认状态转换映射。
- **工作日志：** 支持（时间条目和对活动的评论）。
- **评论：** 不支持。
- **附件：** 支持。
- **过滤：** 范围、状态过滤器。
- **故事点和截止日期：** 支持。

### 6. CalDAV

- **支持的任务类型：** CalDAV 解析 **VTODO** 组件（来自一个或多个日历）。没有有效 VTODO 的事件被跳过。
- **CalDAV 使用的验证：** 应用检查每个 VTODO 是否具有有效的 `UID`、`SUMMARY`（对于 iCal 为 DTSTART）以及（可选）`DUE`、`COMPLETED`、`CATEGORIES`、`DESCRIPTION` 和 `PERCENT-COMPLETE`/`STATUS`（用于处理/完成状态）。不完整的 VTODO 或没有标题的 VTODO 被跳过。
- **导入：** 支持。CalDAV 读取 `DUE` 和 `DTSTART`（用于计划）。已完成的任务可以同步完成状态回来（可选，可配置）。它**不**支持 VTODO 完全同步回来为应用任务子集。
- **状态转换：** 基于完成状态的本地任务自动标记为完成（可配置为回复 `COMPLETED`/`STATUS:COMPLETED`、`PERCENT-COMPLETE:100` 或两者）。CalDAV 集成还会从日历中读取完成状态，并在应用中将匹配的已导入任务标记为完成。
- **工作日志 / 评论 / 子任务 / 附件：** 不支持。
- **过滤：** 按分类（"焦点"列表）；可选的不区分大小写的包含和排除正则表达式应用于任务标题。包含过滤器充当允许列表；排除过滤器在之后应用。
- **自动导入：** 无（集成级别不直接支持；应用会在访问时显示日历任务）。
- **截止日期和计划：** `DUE` 和 `DTSTART` 用于计划。
- **备注：** `DESCRIPTION` 用作任务备注。如果没有 VTODO（仅有 VEVENT），CalDAV 集成会跳过该日历项。没有有效 VTODO 的项目被跳过。

### 7. 日历 (iCal)

- **使用内容：** 应用仅从 iCal 源解析 **VEVENT** 组件。它**不**使用 VTODO（任务）。事件必须具有有效的**开始时间**（DTSTART）；否则会被跳过。全天事件（仅日期的开始时间）也被包含。
- **认证：** **无需登录。** 你只需提供日历 URL（订阅或导出链接）。
- **问题导入：** 来自 iCal URL 的日历事件（VEVENT）。事件显示在日程/计划中；事件描述成为任务备注。**完成状态和时间/日期更改不会同步回去**——从应用的角度看，该源是只读的；如果你在应用中更改了任务，外部日历不会更新。
- **状态转换 / 工作日志 / 评论 / 子任务 / 附件：** 不支持。
- **过滤：** 对事件标题进行基于文本的搜索。日历提供商设置还可以对事件标题应用可选的不区分大小写的包含和排除正则表达式。包含过滤器充当允许列表；排除过滤器在之后应用。
- **自动导入：** 当天事件。
- **时间估算：** 事件时长用作任务时间估算。
- **截止日期：** 事件开始时间（全天或定时）。
- **备注：** 事件描述作为任务备注。
- **URL 格式（Nextcloud 示例）：** 使用"复制订阅链接"，以便 URL 使用正确的格式，例如 `https://<NC-URL>/remote.php/dav/public-calendars/<CALENDAR-ID>?export`。将其粘贴到应用中的"iCal 源 URL"中。**不要**使用"复制私人链接"——该格式用于 CalDAV，而非 iCal。

### 8. Redmine

- **问题导入：** 来自项目的问题。
- **状态转换 / 工作日志 / 评论 / 子任务 / 附件：** 不支持。
- **过滤：** 基于项目；支持范围。
- **自动导入：** 项目的最近 100 个问题。

### 9. Trello

- **问题导入：** 来自看板的卡片。
- **状态转换 / 工作日志 / 评论 / 子任务：** 不支持。
- **附件：** 附件映射和显示。
- **过滤：** 基于看板的过滤。
- **故事点：** 支持。
- **自动导入：** 自动导入卡片到待办清单。

### 10. Linear

- **问题导入：** 支持团队/项目过滤的问题。
- **状态转换：** 基于状态自动标记为完成。
- **工作日志 / 评论 / 子任务：** 不支持。
- **附件：** 附件映射和显示。
- **过滤：** 基于团队和项目。
- **自动导入：** 自动导入问题到待办清单。

### 11. ClickUp

- **问题导入：** 支持团队过滤的任务。
- **状态转换：** 基于状态自动标记为完成。
- **工作日志 / 评论：** 不支持。
- **子任务：** 完整的子任务支持和关系追踪。
- **附件：** 附件映射和显示。
- **过滤：** 基于团队。
- **自动导入：** 自动导入任务到待办清单。

## 实现说明

- **功能最全面的：** Jira 和 OpenProject 支持最多的功能：可配置的状态转换、工作日志提交和高级过滤。OpenProject 增加进度百分比和活动；Jira 增加 JQL、子任务和分配处理。
- **评论重点：** GitHub 和 GitLab 提供可靠的问题导入和评论追踪（带有可选的用户名过滤），但不支持工作日志提交；GitLab 的工作日志支持已弃用。
- **子任务支持：** 除 Jira 外，在列出的提供商中只有 ClickUp 支持完整的子任务导入和关系追踪。
- **面向日历：** CalDAV 和日历 (iCal) 面向日历/待办事项和事件集成（分类、事件时长、当天事件），而非完整的问题追踪功能。它们**不可互换**：iCal 仅使用订阅 URL 和 VEVENT（事件），无需登录且不同步回来；CalDAV 使用服务器登录和仅 VTODO（任务），可选完成同步。使用错误的链接类型（例如在 iCal 中使用 Nextcloud 的"私人链接"或在 CalDAV 中使用"订阅链接"）是集成不工作的常见原因；关于 iCal 与 CalDAV 的概述请参见 [[4.24-Integrations|集成]]。
- **自动导入和轮询：** 大多数提供商支持自动轮询更新，许多支持自动导入新问题到待办清单；确切行为（例如"最近 100 个"与自定义查询）是提供商特定的。

可选功能（例如子任务、附件、向外部系统发回更新）根据外部 API 的支持按提供商实现。
