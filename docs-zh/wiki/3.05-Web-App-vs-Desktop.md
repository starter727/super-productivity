# Web 应用与桌面版对比

本参考文档列举了 Web 应用与桌面版（Electron）应用相比的功能差异和限制。大多数限制源于浏览器安全性（CORS、CSP、沙箱），而非有意移除功能。

## Web 应用中不可用或受限的功能

### 插件系统

需要 Node.js 执行（提升的权限）的插件在 Web 版本中被禁用。当加载此类插件时，应用会显示一个已禁用的占位符，并显示一条错误消息，指出该插件需要桌面版。

### 日历集成

可以通过 `isDisabledForWebApp` 标记为 Web 应用禁用日历提供商，以避免 CORS 失败。当设置了此标记且应用在浏览器中运行时，日历事件请求会返回空结果，而不是执行 HTTP 请求。UI 会显示一个醒目的警告，指出日历集成在浏览器中很可能无法工作，并建议下载桌面版。

### 本地文件系统

- **自动备份到文件系统：** 仅在 Electron（桌面版）和 Android 中可用；Web 浏览器中不可用。
- **本地文件同步：** Web 应用无法同步到本地或网络文件夹；该同步提供商在浏览器中不可用。

### 时间追踪

在 Web 版本中，时间追踪仅在应用打开时工作。浏览器中的空闲时间追踪需要安装 Super Productivity Chrome 扩展。

## 浏览器相关限制

### CORS（跨源资源共享）

WebDAV 同步和日历集成在浏览器中可能因 CORS 而失败。应用会检测与 CORS 相关的失败，并可以显示本地化消息，建议用户检查服务器配置。桌面版应用可以绕过这些请求的 CORS；Web 应用则不能。

### WebCrypto API

Web 应用依赖于现代浏览器对以下功能的支持：

- **Dropbox PKCE 认证：** 需要 `window.crypto.getRandomValues` 和 `window.crypto.subtle.digest`。
- **安全上下文：** WebCrypto（例如 `crypto.subtle`）仅在安全上下文（HTTPS）中可用。当 WebCrypto 不可用或通过非 HTTPS 运行时，应用会显示警告。

### 多标签页实例阻止

Web 版本使用 BroadcastChannel 防止同时运行多个标签页。如果另一个标签页已经打开了应用，新标签页会显示一条阻止消息，要求用户关闭其中一个标签页。

## 存储、内存和性能

### 浏览器存储持久化

Web 应用向浏览器请求持久化存储。如果请求被拒绝，用户会看到一条数据可能丢失的警告。拒绝通过 snack 通知显示。

### 存储配额监控

应用使用 Storage API 估算使用量和配额。当可用空间降至 333 MiB 或更少时，用户会收到磁盘空间不足的警报，应用可能受到影响。

### IndexedDB 配额超出

当 IndexedDB 配额超出时，应用会触发紧急压缩，采用缩短的保留期（24 小时而不是 7 天），并使用断路器避免无限重试循环。

### Service Worker

Web 应用注册一个 Service Worker 用于离线缓存（PWA）。这在 Electron 和 Android 中被禁用。后台行为仅限于浏览器 Service Worker API 允许的范围。

## 文件大小和上传限制（同步）

这些限制由同步服务器强制执行；它们会影响进行同步的 Web 用户：

- **操作负载：** 最大 20 MB。
- **压缩操作：** 最大 10 MB。
- **快照：** 压缩后 30 MB，解压后 100 MB。
- **WebDAV：** XML 响应最大 10 MB；文件内容最大 100 MB。

## 离线和后台处理

### 后台节流

桌面版应用为其窗口禁用后台节流。Web 应用受浏览器的后台标签节流影响，当标签页在后台时，这可能会影响计时器精度和后台任务执行。

### 离线支持

Web 应用使用 Service Worker（生产构建）缓存资源，以提供有限的离线使用。完整的离线行为比桌面版和 Android 更有限。当网络不可用时，应用会显示离线横幅。

## 插件和集成限制（Web）

### iframe 中的插件 API

当插件使用基于 iframe 的 UI 时，出于安全原因，以下 API 方法不可用：

- `registerHeaderButton()`
- `registerMenuEntry()`
- `registerSidePanelButton()`
- `registerShortcut()`
- `registerHook()`
- `execNodeScript()`

### 内容安全策略（iframe 插件）

iframe 插件受到严格的 CSP 限制：

- 外部脚本和样式表被阻止。
- 仅允许同源资源。
- 脚本必须内联在插件 HTML 文件中。

### 用于集成的 Chrome 扩展

Web 版本中的 Jira 集成和空闲时间追踪需要安装 Super Productivity Chrome 扩展。

对于自托管的 Jira 实例，如果服务器配置了适当的 CORS 标头，可以绕过扩展要求：在 Jira 高级设置中启用**直接从浏览器获取 Jira（绕过扩展）**。启用后，应用直接从浏览器发送 API 请求，而不是通过扩展路由。此选项在桌面应用或 Android 上无效。

如果 Jira API 可在与公共问题链接不同的主机上访问（例如内部 API 端点与公共 URL），将**Jira 链接的替代主机**设置为公共主机。该值仅用于在任务详情中构建浏览器 URL，不用于 API 调用。

## Web 应用中不可用的原生功能

Web 版本没有：

- 原生文件系统访问（打开/保存对话框、自动备份到磁盘）。
- 操作系统级通知（它使用 Web Notifications API 替代）。
- 窗口管理（最小化到系统托盘、全局显示/隐藏、自定义标题栏）。
- 系统托盘集成。
- 全局键盘快捷键（仅有页面内快捷键；桌面版可以注册系统级快捷键）。

某些与这些功能相关的 UI 元素在 Web 构建中通过特定于平台的 CSS 或逻辑被隐藏。

## 已记录的 Web 错误情况

- **CORS 错误：** WebDAV（及类似）同步可能报告 CORS 失败，并显示建议检查服务器配置的本地化消息。
- **WebCrypto 不可用：** Dropbox OAuth 和其他加密依赖的功能在 WebCrypto 缺失或不在安全上下文中时会显示警告。
- **存储持久化被拒：** 当浏览器拒绝持久化存储请求时，会通过 snack 通知发出警告。
- **配额超出：** 应用处理多种配额超出变体（例如 Firefox 的 `NS_ERROR_DOM_QUOTA_REACHED`、Safari 的 code 22），并触发紧急压缩。

## 说明

- 项目 README 将 Web 版本描述为"有点受限"，并推荐桌面版以获得完整功能，尤其是日历、文件系统访问和插件支持。
- Android 应用提供"无连接模式"以实现完全离线使用；Web 应用没有等效功能。
- 浏览器中的某些集成功能依赖于 Chrome 扩展来绕过安全限制。
