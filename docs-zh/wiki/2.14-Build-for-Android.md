# 构建 Android 版本

如何构建 Super Productivity 的 Android 应用。

Android 应用在一个单独的仓库中开发，支持**无连接模式**（离线优先）和**仅在线模式**（兼容性）。

## 在哪里找到说明

完整的构建和配置步骤在 Android 仓库中：

**[android/README.md](https://github.com/super-productivity/super-productivity/blob/master/android/README.md)**（在此仓库中：`android/README.md`）

该 README 涵盖：

- 选择启动模式（无连接模式 vs 仅在线模式）
- 在 `app_config.properties` 中设置 `LAUNCH_MODE`
- 逐步构建指南：
  - [无连接模式](https://github.com/super-productivity/super-productivity/blob/master/android/README_OFFLINE.md)（推荐）
  - [仅在线模式](https://github.com/super-productivity/super-productivity/blob/master/android/README_ONLINE.md)
