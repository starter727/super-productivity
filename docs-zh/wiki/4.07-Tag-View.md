# 标签视图（Tag View）

**标签（Tag）** 是一种可以添加到任务上的标签，用于跨领域分类（cross-cutting categorization）。与项目不同（每个任务恰好属于一个项目），任务可以有**零个、一个或多个标签**。

## 标签解决什么问题

标签解决了项目无法解决的**跨领域分类**问题。因为每个任务恰好属于一个项目，项目提供**结构性组织**。标签提供跨项目的**灵活标记**。

例如，一个任务可能属于"后端 API"项目，但被标记为 #urgent、#bug 和 #needs-review。这让你可以：

- **多维分类**：按项目（结构性）和按标签（跨领域）组织
- **灵活筛选**：查看所有项目中所有"紧急"任务，或所有"bug"任务，无论它们在哪个项目中
- **轻量级组织**：标签是简单的标记——没有待办箱、笔记或项目那样的复杂配置

## 标签与项目

| 方面                    | 标签                                             | 项目                                |
| ----------------------- | ------------------------------------------------ | ----------------------------------- |
| **与任务的关系**        | 每个任务零个或多个标签（可选）                    | 每个任务恰好一个项目（必需）        |
| **目的**                | 用于灵活分类的跨领域标签                         | 主要结构组织                        |
| **功能**                | 用于筛选和分组的简单标签                         | 待办箱、笔记、主题、集成            |

任务必须始终属于一个项目，但标签是可选的。你可以为一个任务添加多个标签，以不同方式对其进行分类。

## 多个标签

任务可以有**多个标签**。当你创建或编辑任务时，你可以：

- 在任务标题中使用 #标签名 语法添加多个标签（例如："修复登录bug #urgent #bug #backend"）
- 在添加任务栏中通过复选框选择多个标签
- 在标签编辑对话框中添加或移除多个标签

这让你可以沿多个维度对任务进行分类——按紧急度、类型、领域或任何适合你工作流程的系统。

## 按标签筛选

你可以按标签筛选任务，以查看所有项目中具有特定标签的所有任务。筛选支持：

- **标签名称搜索**：输入部分标签名称以查找具有匹配标签的任务（不区分大小写）
- **无标签**：筛选只显示没有标签的任务

当你查看一个标签时，你会看到来自多个项目且带有该标签的任务。每个任务显示其项目作为徽章，让你了解它属于哪个项目。

## 特殊情况：今日标签

"今日"视图使用一种特殊的**虚拟标签（virtual tag）**模式。任务根据其截止日期（	ask.dueDay === today）出现在今日视图中，而不是因为它们在其标签列表中有一个"今日"标签。这让今日视图专注于基于时间的组织，而标签则保持基于类别的组织。

参见 [[4.01-The-Today-View]] 了解更多关于今日视图如何工作的内容。
