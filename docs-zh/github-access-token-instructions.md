# 如何生成具有权限的 GitHub 访问令牌

要生成 GitHub Personal Access Token：

1. 前往 GitHub 的 [Personal Access Tokens (Classic)](https://github.com/settings/tokens) 页面
   - 注意：细粒度令牌（fine-grained tokens）可能有效，但推荐使用经典令牌（classic tokens），且经过测试
2. 点击"Generate new token (classic)"
3. 选择 `repo` 范围以授予对私有仓库的访问权限
4. 点击"Generate token"并安全存储令牌值
