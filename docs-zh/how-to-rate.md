# 如何给 ***Super Productivity*** 评分

## 评分如何影响应用的可发现性

应用商店的排名算法倾向于平均评分更高的应用。对于一个小型项目来说，即使只有少数低分评价，也可能对平均分以及应用的推荐或展示频率产生不成比例的影响。

如果你觉得 Super Productivity 有用，一个诚实的评分或简短的评论有助于这个项目被更多人看到。

## 馃獰 Windows（Microsoft Store）

1. 前往 [Microsoft Store 页面](https://apps.microsoft.com/detail/9nhfvg8361tw) 或打开 **Microsoft Store** 应用并搜索 **Super Productivity**
2. 滚动到 **评分和评价** 部分
3. 点击你希望给出的星星数量
4. （可选）撰写评价
5. 点击 **提交**

---

## 馃 Android（Google Play Store）

1. 前往 [Play Store 页面](https://play.google.com/store/apps/details?id=com.superproductivity.superproductivity)
